# Nexign Bootcamp Project

## Описание

Это приложение на Spring Boot, разработанное для управления и генерации записей о звонках (CDR) и отчетов об использовании (UDR) для абонентов.
 Приложение предоставляет RESTful API для генерации отчетов и получения данных об использовании для конкретных абонентов или всех абонентов за определенный период времени.

Приложение эмулирует работу коммутатора: абоненты совершают и принимают звонки. 
Оно автоматически генерирует случайные CDR записи для тестирования и позволяет получать UDR и CDR отчеты через REST API. 
Для разработки и тестирования используется in-memory база данных H2.

## Выполненные задачи

- Автоматическая генерация тестовых абонентов и CDR записей при запуске приложения.
- Генерация UDR отчетов для конкретного абонента или всех абонентов.
- Генерация CDR отчетов для конкретного абонента за заданный период времени.

## Зависимости

Проект использует следующие ключевые зависимости:
- **Spring Boot Starter Web** — для создания RESTful API.
- **Spring Boot Starter Data JPA** — для работы с базой данных.
- **H2 Database** — in-memory база данных для разработки и тестирования.
- **Lombok** — для уменьшения шаблонного кода (геттеры, сеттеры, конструкторы).
- **Spring Boot Starter Test и JUnit** — для тестирования приложения.

## Конфигурация базы данных

Приложение использует **in-memory H2 базу данных**.

## Генерация CDR отчёта для абонента
-**Endpoint**: POST `/api/report/{msisdn}/generate-cdr`

-**Описание**:Генерирует отчёт CDR (Call Detail Record) для указанного абонента за заданный период. Возвращает уникальный идентификатор задачи (UUID) и статус начала генерации отчёта.

-**Параметры**:
   - `msisdn` (обязательный, путь): Номер телефона абонента (MSISDN) (например, `7999000009`)
   - `startDate` (обязательный, query): Начальная дата и время в формате ISO-8601 (например, `2025-03-01T19:55:33+00:00`).
   - `endDate` (обязательный, query): Конечная дата и время в формате ISO-8601 (например, `2025-03-31T12:23:59+00:00`).
**Пример запроса**:

```
POST /api/report/7999000009/generate-cdr?startDate=2025-03-01T19:55:33+00:00&endDate=2025-03-31T12:23:59+00:00
```

**Пример ответа**:
```json
{
  "uuid": "123e4567-e89b-12d3-a456-426614174000",
  "message": "CDR report generation started"
}
```
- **Ошибки**:
    - 400 Bad Request: Если формат даты неверный или начальная дата позже конечной.
    - 500 Internal Server Error: Если произошла ошибка при генерации отчёта.

## Получение UDR отчёта для конкретного абонента
- **Endpoint**: GET `/api/{msisdn}`  
- **Описание**: Возвращает отчёт UDR (Usage Detail Record) для указанного абонента. Отчёт включает общее время входящих и исходящих звонков.  
- **Параметры**:  
   - `msisdn` (обязательный, путь): Номер телефона абонента (MSISDN) (например, `7999000009`).  
   - `month` (опциональный, query): Месяц в формате YYYY-MM (например, `2025-03`). Если не указан, отчёт охватывает все доступные данные.  
- **Пример запроса**:  

GET /api/7999000009?month=2025-03
- **Пример ответа**:  
```json
{
  "msisdn": "7999000009",
  "incomingCall": {
    "totalTime": "00:15:30"
  },
  "outgoingCall": {
    "totalTime": "00:45:00"
  }
}
```

 - **Ошибки**:
    - 400 Bad Request: Если формат месяца неверный.
    - 404 Not Found: Если данные для указанного абонента не найдены.

## Получение UDR отчётов для всех абонентов
- **Endpoint**: GET `/api/all`  
- **Описание**: Возвращает отчёты UDR (Usage Detail Record) для всех абонентов. Каждый отчёт включает общее время входящих и исходящих звонков.  
- **Параметры**:  
   - `month` (опциональный, query): Месяц в формате YYYY-MM (например, `2025-03`). Если не указан, отчёт охватывает текущий месяц.  
- **Пример запроса**:  
    
GET /api/all?month=2025-03
- **Пример ответа**:  
```json

    [
      {
        "msisdn": "7999000001",
        "incomingCall": {
          "totalTime": "01:00:00"
        },
        "outgoingCall": {
          "totalTime": "02:30:00"
        }
      },
      {
        "msisdn": "7999000002",
        "incomingCall": {
          "totalTime": "00:45:00"
        },
        "outgoingCall": {
          "totalTime": "01:15:00"
        }
      }
    ]
```

  - **Ошибки**:
     - 400 Bad Request: Если формат месяца неверный.
     - 404 Not Found: Если данные для указанного абонента не найдены.
